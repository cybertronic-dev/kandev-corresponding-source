# DragonLair Kandev corresponding source

This public repository distributes complete corresponding-source archives for
modified Kandev images deployed by DragonLair. Each release asset contains the
patched upstream source, cumulative patch, publisher workflow, source manifest,
license notices, and the exact OCI image digest it corresponds to.

Download the archive attached to the release matching the deployed image digest.
The archive is offered without authentication; no runtime credentials are included.
